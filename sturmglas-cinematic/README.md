# STURMGLAS — Ocean Ultra Cinematic

**Direkt spielen:** https://sturmglas-ocean-cinematic.vercel.app/

Diese Version enthält den zusammengeführten HTML-, JavaScript- und Shader-Spielcode in `index.html` auf dem isolierten Branch `sturmglas-cinematic`.

## Spielumfang

Vier Gebiete, zwölf Spielabschnitte, vier aufgerüstete Schiffe, Sammelmünzen und vier Bosskämpfe. Die Flasche zeigt eine niedrigere Wasserlinie, mit angepassten Spielgrenzen. Jedes Gebiet besitzt abgestufte Atmosphäre: Muschelküste, offene See, Höhle und Piratenschiff. Bosskämpfe enthalten dynamische Bewegungen, Angriffs-Warnungen und Schwachphasen. Die Spielfigur ist das gewählte Schiff.

## Bereitstellung

Der Source-Code liegt hier bei GitHub. Die spielbare HTTPS-Version läuft bei Vercel, wo zusätzlich die Originalgrafiken und Musikdateien ausgeliefert werden. Für eine lokale, vollständige Kopie sind diese Mediendateien ebenfalls erforderlich; sie sind nicht Teil dieses isolierten GitHub-Branches.

Die Browserversion verwendet den WebGL-Wassershader; das Verhalten auf einem konkreten iPhone muss noch live geprüft werden.
