# STURMGLAS – Vier Bosskämpfe (Testversion)

Vier getrennt spielbare Bosskämpfe: Krabbenkönig, Tiefenzahn, Kraken der Tiefe und Leviathan. Das Schiff ist vergrößert und der Flaschenrand sichtbar. Jeder Kampf hat Angriffswarnung, Ausweichen, kurze Schwachphase und Kanonenschüsse.

**[Direkt im Browser spielen](https://sturmglas-vier-bosskaempfe.vercel.app/)**

Die vollständige ZIP mit Quellcode und Grafiken steht als Download im zugehörigen Chat bereit. GitHub dient hier als Dokumentation; die aktuell spielbare Bereitstellung befindet sich auf Vercel.

Entwicklungsstand: erster vierteiliger spielbarer Boss-Prototyp, kein fertiger Endboss-Build für die komplette STURMGLAS-Kampagne. Die weitergehenden geriggten 2,5D-Animationen benötigen noch visuelle Politur.
